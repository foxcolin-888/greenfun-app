# 绿趣全流程管理系统 · 腾讯云轻量部署指南

> 目标：用 **腾讯云轻量应用服务器（约 ¥80/年）** 跑起现有系统，数据库与上传图片挂**持久盘不丢失**，
> 用 **Caddy 自动 HTTPS** 绑定自有域名，后台仅员工登录（账号在 `app.py` 里已设强密码）。
> **业务代码零修改**，与 Render 版完全一致。

---

## 一、购买轻量应用服务器

1. 腾讯云控制台 → **轻量应用服务器** → 新建实例。
2. 地域：选离温州近的（**上海 / 广州**）。
3. 镜像：选 **「Docker 基础镜像」**（已自带 Docker，最省事）；或选 **Ubuntu 22.04 / 24.04**（需自己装 Docker，见下）。
4. 套餐：**2 核 2G / 3–4M 带宽** 即可，活动价约 **¥80–120/年**。小团队 3–4M 带宽够用。
5. 登录方式：设置 **root 密码**（牢记）或用密钥。
6. 购买后记下 **公网 IP**。

## 二、放通防火墙端口

轻量控制台 → 实例 → **防火墙** → 添加规则，放通：
- `80`  (HTTP，Caddy 申请证书用)
- `443` (HTTPS，最终访问)
- `22`  (SSH，登录服务器用)
> 业务端口 8000 只在容器内部，由 Caddy 代理，无需对外放通。

## 三、登录并装 Docker（若镜像没带）

- 网页终端：控制台 → **OrcaTerm** 一键登录；或本地 `ssh root@你的公网IP`。
- 若选 Ubuntu 镜像，先装 Docker（国内镜像快）：
  ```bash
  curl -fsSL https://get.daocloud.io/docker | sh
  systemctl enable --now docker
  # 装 docker compose 插件
  curl -L "https://get.daocloud.io/docker/compose/releases/latest/download/docker-compose-linux-x86_64" \
    -o /usr/local/bin/docker-compose
  chmod +x /usr/local/bin/docker-compose
  docker --version   # 看到版本即成功
  ```

## 四、上传项目代码

**方式 A（推荐，仓库已公开）：** 服务器上直接拉
```bash
apt update && apt install -y git
git clone https://github.com/foxcolin-888/greenfun-app.git
cd greenfun-app
```
**方式 B（本地传入）：** 本机用 WinSCP / scp 把整个 `greenfun-app` 文件夹传上去（**不要**传 `greenfun.db`、`.tmp/`、`web/uploads/` 等运行时文件）。

## 五、配置域名并启动

1. 编辑 `docker-compose.yml`，把 `caddy` 服务的 `SITE` 改成你的域名：
   ```yaml
   environment:
     - SITE=www.lvqu.com      # ← 改成你自己的域名
   ```
2. 同样在 `Caddyfile` 顶部把 `email admin@lvqu.com` 改成你的邮箱（用于证书注册）。
3. 启动：
   ```bash
   docker compose up -d
   ```
   首次会自动构建镜像并拉取 Caddy，约 1–2 分钟。看到 `greenfun-app` 与 `greenfun-caddy` 两个容器 `Up` 即成功：
   ```bash
   docker compose ps
   ```

## 六、域名解析 + 备案（国内必做）

1. **DNS 解析**：在你的域名服务商（腾讯云 DNSPod / 阿里云等）添加 **A 记录**：
   - 主机 `www` → 你的公网 IP
   - 主机 `@`（根域名）→ 你的公网 IP
2. **ICP 备案**：域名指向国内服务器必须备案（免费，腾讯云控制台有「备案」入口，按指引传营业执照+法人信息，约 1–2 周）。
   - 备案期间可先用 **IP 直接访问**（`http://公网IP`）验证系统是否正常，备案通过后再用域名。
   - 若想**跳过备案**，可把域名 NS 转到 Cloudflare、服务器放境外（见指南末尾「备选」），但国内员工访问会稍慢。
3. 备案通过 + 解析生效后，Caddy 会自动申请 Let's Encrypt 证书，访问 `https://www.lvqu.com` 即上 HTTPS。

> 想先不绑域名、纯 IP 测试？把 `docker-compose.yml` 的 `SITE` 改成 `:80`（Caddy 走纯 HTTP），
> 访问 `http://公网IP` 即可，后续再改回域名。

## 八、数据备份（重要）

数据库和上传图片都在 `greenfun_data` 卷。定期备份：
```bash
# 在服务器上执行，把持久卷打包到当前目录 backup-日期.tar.gz
docker run --rm -v greenfun_data:/data -v $(pwd):/backup alpine \
  tar czf /backup/backup-$(date +%F).tar.gz -C /data .
```
把生成的 `backup-*.tar.gz` 下载到本地保存。恢复时解包回 `/data` 即可。

## 九、升级 / 改代码后重新部署

```bash
cd greenfun-app
git pull                 # 或重新传文件

```
数据在持久卷，不会被覆盖。

## 十、常用运维命令

```bash
docker compose ps            # 看容器状态
docker compose logs -f app  # 看后端日志
docker compose restart      # 重启
docker compose down         # 停止（数据卷保留）
```

## 十一、故障排查

- **访问打不开**：检查防火墙 80/443 是否放通；`docker compose ps` 是否都为 Up；`docker compose logs -f caddy` 看证书是否申请成功（域名须已解析到本机 IP）。
- **Caddy 报证书失败**：确认域名 A 记录已生效（`ping 你的域名` 应回公网 IP）；或先把 `SITE` 临时改 `:80` 用 HTTP 验证业务本身没问题。
- **后台改了不生效 / 数据丢失**：确认 `docker-compose.yml` 里 `DB_PATH=/data/greenfun.db`、`UPLOAD_DIR=/data/uploads` 且 `greenfun_data` 卷已挂载（默认已配好）。

## 备选：想完全零成本 / 不想备案

- **Cloudflare Pages + D1**：永久免费、全球 CDN、自定义域名最简单，但需把 `app.py` 改写成 Cloudflare Worker + D1 数据库（约改路由层）。需要我再做可说。
- **Oracle Cloud Always Free**：2 台 ARM 云主机永久免费、不改代码，但首次要抢免费机型、需一点 Linux 运维，国内访问一般。
- **国际 VPS（Hetzner/Vultr）**：~¥35/月，不改代码、无需备案，海外快国内一般。
