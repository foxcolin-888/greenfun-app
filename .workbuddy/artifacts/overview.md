# 生图积分扣费与多模型接入 — 迭代概览

## 本次完成
1. **新增积分系统**：`credits` 表 + `credit_transactions` 流水表，支持管理员充值/扣减、员工生图自动扣费、失败自动回滚。
2. **扩展内置生图模型**：在方案设计页可直接选择 Pollinations（多个模型，免费免 Key）、Hugging Face FLUX.1-schnell、硅基流动、豆包 Seedream 系列、OpenAI DALL·E 3 / GPT-Image-1。
3. **平台级 API Key 机制**：管理员在系统设置配置一次 Key，全站员工共用，无需每人申请；未配置时员工可临时填写（仅本次使用）。
4. **豆包 401 精确提示**：捕获 HTTP 401/403/429/5xx 并给出明确中文提示，帮助用户判断是 Key 无效、模型未开通还是服务异常。
5. **前端积分展示**：顶部导航显示积分余额，方案设计页显示「本次消耗 / 余额」，新增「积分管理」页面（admin/manager）。

## 豆包 401 排查建议
401 说明请求格式正确，但 Key 未通过火山方舟鉴权。请检查：
1. Key 是否从 [火山方舟控制台](https://console.volcengine.com/ark/) 的「API Key 管理」获取（不是豆包大模型、不是其他火山子产品）。
2. 该 Key 是否已开通「生图」权限，且已接入 doubao-seedream-* 模型。
3. Key 是否复制完整（无空格、无多余字符）。
4. 如 Key 泄露或被禁用，请重新创建并更新到系统设置→平台级 API Key。
